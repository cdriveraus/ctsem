This article works through one analysis from start to end: the model, the data, specifying and fitting a model, reading the results, adding a covariate and checking the model. It assumes ctsem and its Julia engine are installed, as the README describes.

library(ctsem)
library(ggplot2)

The model

A ctsem model describes one or more latent processes that change over time, and the variables measured at the times they were observed. Within each subject the processes 𝜼(t)\boldsymbol\eta(t) follow

d𝜼(t)=(A𝜼(t)+𝒃+M𝝌(t))dt+Gd𝑾(t) \mathrm{d}\boldsymbol\eta(t) = \big(A\,\boldsymbol\eta(t) + \mathbf b + M\boldsymbol\chi(t)\big)\,\mathrm{d}t + G\,\mathrm{d}\mathbf W(t)

and the measurements are

𝒚(t)=Λ𝜼(t)+𝝉+𝝐(t),𝝐(t)∼N(𝟎,Θ) \mathbf y(t) = \Lambda\,\boldsymbol\eta(t) + \boldsymbol\tau + \boldsymbol\epsilon(t), \qquad \boldsymbol\epsilon(t) \sim N(\mathbf 0, \Theta)

Each symbol is a matrix of ctModel():

Matrix Symbol Holds Default
DRIFT AA auto effects (diagonal) and cross effects between processes free
CINT 𝒃\mathbf b continuous time intercepts zero
DIFFUSION GG size and correlation of the random shocks to the processes free
TDPREDEFFECT MM effects of time dependent predictors 𝝌\boldsymbol\chi free
T0MEANS the processes’ values at each subject’s first observation free, varying over subjects
T0VAR their variance at the first observation covered by the random T0MEANS
LAMBDA Λ\Lambda loadings of the measured variables on the processes must be given
MANIFESTMEANS 𝝉\boldsymbol\tau intercepts of the measured variables free, varying over subjects
MANIFESTVAR Θ\Theta measurement error free standard deviations

The drift matrix describes how the processes change. With a negative auto effect, a process on its own returns towards its equilibrium after a shock. A cross effect is the effect of one process on the rate of change of another. Whether the processes together return to equilibrium depends on the whole drift matrix, which vignette('dynamics') explains. The diffusion describes the random shocks that move the processes between observations, and so carry forward in time. Measurement error affects only the observation it belongs to. A time dependent predictor, such as an intervention, shifts the processes at the times it is observed, and the dynamics carry the shift forward.

Any parameter can differ between subjects, as a random effect, and depend on subject level covariates (time independent predictors). By default the initial states and the intercepts of the measured variables differ between subjects, which allows for stable differences between people.

With type = 'dt' the same matrices describe a discrete time model, in which DRIFT holds the autoregressive and cross-lagged coefficients from one occasion to the next.

Data

ctsem takes data in long format: one row per subject and occasion, with a column for the subject id, one for the time, and one for each measured variable and predictor.

  • Times are numbers, in whatever unit suits the processes, such as hours, days or years. They need not be equally spaced and can differ between subjects. The estimated effects are per unit of time, so the unit decides their scale. A unit over which the processes change noticeably, but do not settle completely, usually works best.
  • A missing value is NA. A row can have some variables observed and others missing.
  • A time independent predictor must have the same value on every row of a subject.
  • A time dependent predictor is an input at the time of its row, and zero means no input.

The data for this article are simulated, so that the estimates can be compared with the values that generated them. One hundred people rated their stress and mood about once a day, at irregular times, for a month or so, and some ratings are missing. In the generating model stress lowers mood but mood does not affect stress, each person has their own typical stress and mood, and older people tend to be more stressed. age is standardised.

set.seed(1)
gen <- ctModel(type = 'ct', silent = TRUE,
  manifestNames = c('stress', 'mood'), latentNames = c('stress', 'mood'),
  LAMBDA = diag(2), TIpredNames = 'age',
  DRIFT = matrix(c(-0.5, 0, -0.25, -0.3), 2, 2, byrow = TRUE),
  DIFFUSION = matrix(c(0.8, 0, 0, 0.6), 2, 2, byrow = TRUE),
  CINT = matrix(0, 2, 1), T0MEANS = matrix(0, 2, 1), T0VAR = diag(1, 2),
  MANIFESTMEANS = matrix(c('mm_stress|param|TRUE|0.5|age=0.3',
    'mm_mood|param|TRUE|0.5'), 2, 1),

Specifying the model

Each process is measured by one variable, with a loading of 1, so LAMBDA is an identity matrix. ctModel() takes the names of the time and id columns from its time and id arguments, which default to 'time' and 'id'.

model <- ctModel(LAMBDA = diag(2),
  manifestNames = c('stress', 'mood'), latentNames = c('stress', 'mood'))

Printing the model shows each matrix, with the name of each free parameter and the value of each fixed one. Everything not given to ctModel() takes the defaults in the table above. ctModelLatex(model) writes the same model as equations, and opens them as a pdf if LaTeX is installed:

The first line is the distribution of the random effects. Each person’s starting values and measurement intercepts are drawn from a normal distribution, on the raw scale of the parameters, and then transformed. The next two lines are the dynamics, the two after them the measurement, and the last line the distribution of the random shocks over an interval.

To change a matrix, give it to ctModel(). A number fixes a cell, and a name estimates it. This drift matrix would fix the effect of mood on stress at zero:

DRIFT = matrix(c('drift_stress',      0,
                 'drift_mood_stress', 'drift_mood'), 2, 2, byrow = TRUE)

The same model can be written in lavaan, Mplus or formula syntax, which vignette('model-syntax') describes.

Fitting

fit <- ctFit(dat, model, cores = 2)

By default ctFit() finds the maximum likelihood estimates, integrating over the latent states and over the differences between people. cores sets the number of CPU cores to use. priors = TRUE adds weakly informative priors, which helps with small data sets, and optimize = FALSE samples the posterior instead of optimising. vignette('uncertainty') compares these.

Reading the results

summary(fit) prints every part of the result. The population values of the parameters are in popmeans:

Each row is a parameter, with its estimate (mean), standard error (sd) and 95% interval.

  • drift_stress and drift_mood are the auto effects, per day. On its own, stress one unit above its equilibrium changes at a rate of about -0.5 units a day, and after one day about exp(-0.54), or 0.58, of the deviation is left.
  • drift_mood_stress is the effect of stress on mood: more stress lowers the rate of change of mood. drift_stress_mood, the effect of mood on stress, is small and its interval includes zero.
  • diff_stress and diff_mood are the standard deviations of the random shocks. diff_mood_stress is a parameter for their correlation, and is not itself a correlation. The correlation is in s$parmatrices and ctSummaryMatrices(fit)$estimate$DIFFUSIONcor.
  • mvarstress and mvarmood are the measurement error standard deviations.
  • mm_stress and mm_mood are the average levels of the two variables, and T0m_stress and T0m_mood where the processes start relative to them.

The drift matrix as a whole decides whether the processes are stable and how fast they change. They are stable when every eigenvalue has a negative real part, and the eigenvalues give the time scale:

est <- ctSummaryMatrices(fit)$estimate
est$DRIFT
#>            stress        mood
#> stress -0.5380869  0.03192653
#> mood   -0.2346860 -0.34671108
eigen(est$DRIFT)$values
#> [1] -0.4831845 -0.4016134
log(2) / abs(eigen(est$DRIFT)$values)    # half-lives, in days
#> [1] 1.434539 1.725906

Both eigenvalues are negative, and a disturbance to the system halves in one and a half to two days.

How much people differ is in popsd, the standard deviations of the random effects:

Effects over time

A cross effect in a continuous time model is an effect on a rate of change. The effect of stress on mood over a given time interval, the cross-lagged coefficient a discrete time model would estimate, depends on the interval:

ctDiscretePars(fit, times = seq(0, 10, by = 0.1), plot = TRUE)

A unit of stress is followed by lower mood, most strongly two to three days later, when the effect is about -0.2. summary() of ctDiscretePars(fit, times = ...) gives the peaks and their times, and vignette('dynamics') explains these curves.

Individual trajectories

ctPredict() gives the model’s predictions for each person over time. The plot shows the observations, and lines for each person’s expected values given their earlier observations, with 95% intervals. The lines jump at each observation, as it updates the prediction. kalmanvec = 'ysmooth' uses all of a person’s observations instead.

ctPredict(fit, subjects = 1:2, plot = TRUE)

ctSubjectPars() gives each person’s estimated parameters, here their own typical levels and starting states. They are close to the levels that generated the data:

sp <- ctSubjectPars(fit)
dim(sp)                     # draws x subjects x parameters
#> [1]   1 100   4
cor(sp[1, , 'mm_stress'], truelevels$mm_stress)
#> [1] 0.9474248

A covariate

In the model, a covariate is a time independent predictor (TIpredNames), and its effects are given in the tipreds field of the parameters it affects. With tipredDefault = FALSE it affects only those.

model2 <- ctModel(LAMBDA = diag(2),
  manifestNames = c('stress', 'mood'), latentNames = c('stress', 'mood'),
  TIpredNames = 'age', tipredDefault = FALSE,
  MANIFESTMEANS = c('mm_stress, tipreds=c(age)', 'mm_mood'))
fit2 <- ctFit(dat, model2, cores = 2)
