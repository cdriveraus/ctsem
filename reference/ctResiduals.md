# Extract Standardized Residuals from a ctsem Fit

This function takes a fit object from the ctsem package and extracts the
standardized residuals.

## Usage

``` r
ctResiduals(fit)
```

## Arguments

- fit:

  A fitted model object generated by the ctsem package.

## Value

A data table containing the standardized residuals for each subject and
time point, with subjects labelled by their ids in the data.

## Details

This function uses the
[`ctKalmanArray`](https://cdriveraus.github.io/ctsem/reference/ctKalmanArray.md)
function to calculate the standardized residuals and then extracts and
formats them as a data table. The standardized residuals represent the
differences between the observed and predicted values, divided by the
standard errors of the observations.

## See also

[`ctKalmanArray`](https://cdriveraus.github.io/ctsem/reference/ctKalmanArray.md)

## Examples

``` r
data.table::setDTthreads(1) #ignore this line
# Example usage:
residuals <- ctResiduals(ctstantestfit)
```
