# Whether the optimiser would take \`start\`: the engine's own rule for its first trial (\`ctsem_start_usable\`), on the objective it climbs. A check that cannot run says no, and the default start is used.

Whether the optimiser would take \`start\`: the engine's own rule for
its first trial (\`ctsem_start_usable\`), on the objective it climbs. A
check that cannot run says no, and the default start is used.

