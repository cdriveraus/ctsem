# The free population parameters of a model, one row each, in parameter order

\`.ctMatsetupFreeRows()\` with the deduplication and ordering every
caller of this shape also wanted.

## Usage

``` r
ctMatsetupFreePars(m, ...)
```

## Arguments

- m:

  matsetup, as a data.frame.

- ...:

  passed to \[.ctMatsetupFreeRows()\].

## Value

\`m\`, subset to one row per parameter and ordered by parameter number.
