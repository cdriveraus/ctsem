# AnomAuth

A dataset containing panel data assessments of individuals Anomia and
Authoritarianism.

## Format

data frame with 2722 rows, 14 columns. Column Y1 represents anomia, Y2
Authoritarianism, dTx the time interval for measurement occasion x.

## Source

See [doi:10.1037/a0027543](https://doi.org/10.1037/a0027543) for
details.
